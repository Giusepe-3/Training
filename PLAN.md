## Aggressive Double Progression

For each working set:
1. Stay in the prescribed rep range (e.g., 5–7).
2. Hit top of range across all sets at prescribed RPE → **add weight NEXT session.**
3. New weight typically drops you back to bottom of range. Climb again.

**Don't sit at the same weight for 2 weeks.** If reps stall, vary rep range or apply intensity techniques.

**Increments (every session if top of range hit):**
- Big compounds (bench, squat, deadlift): +2.5 kg
- Smaller compounds (OHP, row, weighted pull-up): +2.5 kg
- Isolation (curls, lateral raises): +1–2 kg or +1 rep across sets

**RPE prediction calibration:** if you consistently come in at RPE 6.5 when prescribed RPE 8, weights bump immediately. Don't wait two weeks.

**Intra-session calibration (anti-Wk 1 rule):** if first set lands RPE < 7 at prescribed weight → bump load **mid-session**, don't finish at warm-up intensity.

## Intensity Techniques (Wk 5+)

**Drop sets** — final set of an isolation, drop ~30% load, hit failure. 1× per movement per session.
**Myo-reps** — top set to RPE 9, rest 15s, 3–5 reps, rest 15s, repeat 3 mini-sets. Time-efficient brutal stimulus.
**Lengthened partials** — once you hit RPE 9 in full range, continue with bottom-half reps until lockout fails. Use on cable fly, lateral raise, preacher curl, RDL, leg curl.

Apply to **isolation only** during Wks 5–7. Add to compounds (back-off drop sets on bench, squat) Wk 8+.

## Red Flags (Adjust Protocol)

- 3 consecutive sessions where target reps drop at same weight → vary rep range OR drop weight 5% and rebuild OR apply intensity techniques
- Resting HR > 10 bpm above normal for 3+ days → cut volume 20% for 1 week, sleep more, audit nutrition
- Joint pain (not muscle soreness) lasting > 3 days → swap exercise variation, do not push through
- Body weight dropping >0.5 kg/week for 2+ weeks → eat more, you're in deficit not maintenance
- HR drift up at same easy run pace → fatigue accumulation, drop a Thu run
