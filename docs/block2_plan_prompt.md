## EVIDENCE BASE — apply all of it

1. **Volume progression / injury.** 10%-rule evidence is weak; what kills runners is spikes. Use **ACWR 0.8–1.3** (>1.5 = danger) on weekly load AND the long-run rule: **each long run ≤110% of the longest run in the past 30 days** (30%+ single-run spikes = +64% injury risk, 5,200-runner study). After the 17-day gap the 30-day lookback is nearly empty — first long runs restart low (~10–12k) regardless of how easy they feel.
2. **Intensity distribution.** ~80% low intensity. Best 16-wk result in trained runners: **pyramidal first half → polarized second half** (Filipas 2022); polarized beat pyramidal in recreational marathoners (2025, n=120). So: base weeks = Z2 + touch of threshold (pyramidal), sharpening weeks = Z2 + race-pace/VO₂ work (polarized-ish). Individual response varies — hold the 80% easy floor either way.
3. **Strength for runners.** Heavy-load + plyometric work 2–3×/wk for 8–12 wks improves running economy small-to-moderate (Balsalobre-Fernández 2016; Blagrove 2018; 2024 SR/MA). **Maintenance dose: strength holds ≥32 wks at 1–2 sessions/wk, low sets, IF intensity (load) is kept** (Spiering 2021). → 2×/wk full-body, few hard sets, keep load, slow-steady bump gate per CLAUDE.md. Plyos: only if tibia fully quiet, minimal dose, late block at earliest — bone gate overrides economy gain.
4. **Concurrent interference.** Schumann 2022 (43 studies): running does NOT meaningfully blunt strength/hypertrophy any schedule; only explosive power suffers (−28%, worst same-session). → scheduling is free; protect the two quality runs and the long run from hard leg work within ~24 h, otherwise don't sweat sequencing.
5. **Taper.** 2 weeks (8–14 d optimal): volume **−41–60%, exponential/progressive, intensity and frequency unchanged** (Bosquet 2007; 2023 PLOS MA). W11 ≈ −25–30%, W12 ≈ −50–60%, keep strides + short race-pace touches.
6. **Bone re-entry.** Graduated return: distance before speed, symptom-led, ~10%/wk on impact volume, 1–2 rest days, reduce-then-progress (Warden). Pinpoint bone pain = full stop, not modify. All W1–4 running easy Z2; no intensity until impact volume is established (~W4–5).
7. **Cadence.** +5–10% step rate cuts tibial acceleration and knee/PFP load 20–30% at no metabolic cost (Heiderscheit 2011). User needs only +3–5% (159–164 → 165+). Protocol: metronome/watch alarm on ALL easy runs from W1 (bone-protective exactly when bone is vulnerable), target 165–168, habitual by W8 — pace-linked cadence is the standing failure, so train it at EASY pace.
8. **Weight → performance.** ~2.5–3.5 s/km per kg at long-race pace; 77.6→73 kg ≈ 4–7 min over 30K. BUT low energy availability = **2.5× bone-stress-injury risk**, and low-carb training days independently harm bone. → cut is real but subordinate: start ~W2–3 once rhythm holds, **−400 kcal/d max, 0.3–0.5 kg/wk**, protein ≥2 g/kg, calcium+vit D adequate, **never low-carb around runs** (carbs concentrated pre/during/post run days), **maintenance from ~W9 through race**. Any bone twinge → cut pauses same day.
9. **Fueling / gut training.** Race ~2:50–3:00 → race-day target **60–90 g carbs/h** (2:1 glucose:fructose above 60). Gut is trainable: start ~30 g/h on long runs ~W3, +10 g/h weekly-ish, rehearse full race protocol on the 2 biggest long runs. No fasted long runs (bone + evidence #8).
10. **Long-run cap.** Diminishing returns past 2.5–3 h; damage compromises the next week. **Cap ~2:30–2:45.** Peak long run ~24–26k (at his pace = at the cap); race exceeds longest run — normal and fine (marathoners peak 30–32k). Late-block long runs get race-pace finishing segments (e.g., final 4–6k @ 5:40–5:50) instead of more distance.
