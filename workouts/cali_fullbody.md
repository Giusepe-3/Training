# Cali Full Body — Mon AM / Fri AM

**Created 2026-08-31.** Replaces the barbell `upper_A / upper_B / lower_A / lower_B` split (DORMANT — user moved to a calisthenics gym, self-programmed, 2×/wk at fixed Mon AM + Fri AM slots).

**Focus:** Full body, upper-dominant. **Running owns the legs — this session must not tax them.**
**Duration:** ~60 min (8 WU + 49 work + 3 CD)
**Block:** Block 2, 30K sub-3:10, race Sun Oct 11 2026.

---

## ⚠️ The governing constraint

**Legs are RPE 6 hard-capped, every session, no exceptions.** Monday precedes Tuesday's run; Friday precedes Sunday's long run. There is no week in this block where trashed legs are acceptable. Upper body carries all the intensity; legs get quality reps and stability work only.

Corollary: **do not "fix" the low leg volume.** It is deliberate. Lifting is at maintenance and running is the goal.

## Why Tibialis Raise is non-negotiable

**The tibia gates this entire block** (right-tibia stress-fx watch May–Jun 2026, rehabbed clean). Anterior tib is the shin's armour and is trained by essentially nothing else — not running, not walking, not any other movement in this session. It stays in every cali day for the life of the block. If time runs out, cut D3, then D2. **Never D1.**

## Progression — SLOW STEADY (per CLAUDE.md, user directive)

Bodyweight training progresses by **leverage, not load**. The gate is unchanged in spirit: **all sets at the top of the rep range AND every set RPE ≤7 → advance one step on the ladder.** A set creeping to RPE 8 = hold and clean it. Reps before leverage.

| Movement | Regression ← → Progression ladder |
|----------|-----------------------------------|
| Push-up | wall → incline bar → knee → **strict floor** → feet elevated → archer → one-arm progressions |
| Inverted Row | bar high (upright) → **bar hip height** → bar lower → feet elevated → tuck front lever row |
| Pull-up | dead hang → scap pull-up → **band-assisted / 5 s negatives** → strict → weighted |
| Pike Push-up | hands elevated → **floor pike** → feet elevated → wall-supported HSPU |
| Bulgarian Split Squat | assisted (hold support) → **BW** → paused → deficit (⚠️ only if running volume allows) |
| Single-Leg RDL | fingertips on support → **BW** → BW + reach → light DB |
| Tibialis Raise | **BW heels-on-wall** → BW slow eccentric → weighted (plate on toes / tib bar) |
| Hanging Knee Raise | lying knee raise → **hanging knee** → hanging knee to chest → toes-to-bar |

**Never re-open at a level that produced RPE 9+.** Off a layoff: seed conservative, autoregulate up — loads landing under prescription is EXPECTED, not a flag.
