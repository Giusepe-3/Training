# Session Log Template — Lifting Day

Two-touch logging: **AM** on wake, **PM** before bed (after workout + macros tallied).

Copy into `logs/session_log.md` under the day's bullet. Lifting day uses this file. Rest/run-only day → use `daily.md`.
